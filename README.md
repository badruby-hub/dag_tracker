# Спред-трекер (Bybit ⇄ OKX)

Telegram-бот + Mini App, который сканирует **perpetual futures (бессрочные
фьючерсы)** — все монеты, которые торгуются против USDT на **Bybit, OKX,
Binance, Bitget, Gate.io и MEXC** — и показывает те, где разница в цене
между какими-то двумя из этих бирж превышает порог (по умолчанию 7%).

Важно: это именно фьючерсы/перпетуалы, не спот. У каждой биржи это
отдельный рынок со своим эндпоинтом — `category=linear` у Bybit,
`instType=SWAP` у OKX, `fapi.binance.com` у Binance, `productType=usdt-futures`
у Bitget, `/futures/usdt/` у Gate.io, `contract.mexc.com` у MEXC.

Цены берутся с **публичных** эндпоинтов бирж — API-ключ не нужен, ключи
понадобятся позже, только если захочешь автоматизировать сами сделки.

## Что внутри

- `report.js` — чистая логика скана и построения отчёта, без привязки к
  Express/Vercel — использует и бот на PM2, и функция на Vercel
- `api/prices.js` — Vercel serverless-функция, отдаёт `/api/prices`
- `vercel.json` — говорит Vercel отдавать `public/` как корень сайта
- `server.js` — локальный dev-сервер (`node server.js` → `localhost:3000`),
  на проде не нужен, если Mini App хостится на Vercel
- `bot.js` — телеграм-бот на Telegraf: `/start`, кнопка «Проверить сейчас», `/check`
- `exchanges.js` — тянет ВСЕ тикеры с каждой из 6 бирж за один запрос на
  биржу, сопоставляет монеты по базовому активу (например `FROGIUSDT` на
  Bybit/Binance/Bitget/MEXC, `FROGI-USDT` на OKX, `FROGI_USDT` на Gate.io —
  для каждой биржи свой формат тикера, но база одна), и для каждой монеты,
  что торгуется на 2+ биржах, ищет лучшую пару: где дешевле купить, где
  дороже продать
- `config.js` — порог алерта и фильтр минимальной ликвидности
- `public/` — Mini App (HTML/CSS/JS)

## Архитектура: бот отдельно, Mini App отдельно

Бот использует long polling (`bot.launch()`) — ему нужен процесс, который
не останавливается. Vercel — serverless: код там живёт только на время
одного запроса, постоянного процесса не бывает в принципе. Поэтому:

- **Бот** — как и сейчас, живёт на твоём сервере под PM2. Ему для этого
  вообще не нужен Express — он импортирует `report.js` напрямую, без HTTP.
- **Mini App + `/api/prices`** — переезжают на Vercel: статика из `public/`
  плюс `api/prices.js` как serverless-функция.

Оба места используют один и тот же `report.js`, поэтому логика скана не
дублируется и не может разъехаться между ботом и приложением.

## Как считается спред

Для каждой монеты, что торгуется на 2 и более биржах из списка:

1. Перебираем все пары бирж, где эта монета есть
2. Берём **ask** (цена продавца) там, где дешевле — это цена покупки
3. Берём **bid** (цена покупателя) там, где дороже — это цена продажи
4. Спред % = (цена продажи − цена покупки) / цена покупки × 100
5. В карточку попадает пара с максимальным спредом (например если монета
   на всех 6 биржах, но по-настоящему интересна разница только между
   Gate.io и Binance — покажет именно её, а остальные биржи, где она тоже
   торгуется, упомянет отдельной строкой)

Это реальная арбитражная экономика, а не просто "цена минус цена" — bid и
ask всегда чуть расходятся, и именно по ним реально исполняются сделки.

Плечевые токены (3L/3S, UP/DOWN, BULL/BEAR — они есть у Binance, OKX и
др.) исключены из сравнения: их цена — это производная от движения монеты,
а не сама монета, сравнивать их с споткой было бы некорректно.

Монеты с суточным объёмом ниже `MIN_VOLUME_USDT` на бирже — эта биржа для
них не учитывается (но монета может остаться в списке за счёт других
бирж). Без этого фильтра в топе были бы мёртвые пары, где "спред" 20-50% —
это не возможность заработать, а просто нет ликвидности и котировки старые.

## Защита от фейковых спредов (важно)

Тикеры монет **не уникальны глобально** — разные биржи листят разные
активы под одинаковым названием, особенно среди мем-монет. Например: OKX
торгует настоящим Ronin под тикером `RON`, а на Bitget под `RON` внутри
фьючерсов может оказаться вообще другой, никак не связанный токен (сам
Ronin у Bitget называется `RONINUSDT`). Если сравнить эти цены как будто
это один и тот же актив — получится "спред" в тысячи и миллионы процентов,
хотя реального арбитража там нет вообще.

От этого есть защита — `MAX_SANE_SPREAD_PERCENT` (по умолчанию 50%): если
у монеты "лучший" спред больше этого значения, она **не показывается** —
считаем это совпадением тикеров, а не возможностью. В приложении и в
ответе бота видно, сколько таких монет отфильтровано за раз ("скрыто как
подозрительные"), чтобы не гадать, работает ли фильтр.

Также у каждой монеты в карточке рядом с названием биржи показывается
точный тикер контракта (например `Bitget · 1000PEPEUSDT`) — так сразу
видно настоящее имя инструмента, под которым его искать на бирже, и
удобно перепроверить руками, если возникли сомнения.

Отдельно учтена ситуация, когда одна и та же монета торгуется у одной
биржи как `1000PEPEUSDT` (контракт на 1000 токенов сразу — так делают,
когда токен слишком дешёвый), а у другой — просто `PEPEUSDT`. Цена
`1000PEPEUSDT` автоматически делится на 1000 перед сравнением, чтобы
спред считался корректно, а не был искажён в 1000 раз.

## 1. Установка

```bash
npm install
cp .env.example .env
```

Заполни `.env`:

- `BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather) (команда `/newbot`)
- `PUBLIC_URL` — публичный адрес сервера (нужен для кнопки Mini App в боте)
- `THRESHOLD_PERCENT` — порог спреда в %, по умолчанию `7`
- `MIN_VOLUME_USDT` — минимальный суточный объём, по умолчанию `20000`

## 2. Запуск бота локально (то же, что у тебя на PM2)

```bash
pm2 start bot.js --name frogi-bot
```

Или без PM2, для быстрой проверки:

```bash
node bot.js
```

Бот больше не поднимает Express — он только слушает Telegram и дергает
`report.js` напрямую. Напиши боту `/start`, потом «Проверить сейчас» или `/check`.

## 3. Деплой Mini App на Vercel

Самый простой путь — через GitHub:

1. Залей этот проект (весь, с папками `api/` и `public/`) в свой репозиторий на GitHub
2. Зайди на [vercel.com](https://vercel.com) → *Add New* → *Project* → выбери репозиторий
3. Vercel сам всё определит по `vercel.json` — жать почти ничего не надо,
   Framework Preset можно оставить *Other*
4. В *Environment Variables* (в настройках проекта на Vercel, не в `.env` —
   локальный `.env` на Vercel не читается) добавь:
   - `THRESHOLD_PERCENT` = `7`
   - `MIN_VOLUME_USDT` = `20000`
   - `MAX_SANE_SPREAD_PERCENT` = `50`
5. Жми *Deploy*. Через минуту получишь адрес вида `https://frogi-tracker.vercel.app`

Или через CLI, если так привычнее:

```bash
npm i -g vercel
vercel        # деплой в preview
vercel --prod # деплой в прод
```

Проверь: открой `https://твой-проект.vercel.app` в браузере — должен
показаться интерфейс, кнопка обновления должна подтягивать монеты.
Отдельно можно дёрнуть `https://твой-проект.vercel.app/api/prices` —
увидишь сырой JSON, как раньше на `localhost:3000`.

## 4. Подключи адрес Vercel к боту

В `.env` **на сервере, где крутится бот через PM2**, пропиши:

```
PUBLIC_URL=https://твой-проект.vercel.app
```

и перезапусти процесс:

```bash
pm2 restart frogi-bot
```

Дополнительно — зарегистрируй тот же адрес у
[@BotFather](https://t.me/BotFather) → выбери бота → *Bot Settings* →
*Menu Button* → вставь `https://твой-проект.vercel.app`, чтобы приложение
открывалось и через меню чата, не только через кнопку в `/start`.

## 5. Как пользоваться в приложении

- Открыл → жмёшь 🔄 в правом верхнем углу → сканируются все монеты
- По умолчанию показываются только те, где спред ≥ порога — это и есть суть
- Строка поиска работает по-другому: если что-то ввёл — покажет эту монету
  независимо от порога (чтобы можно было проверить конкретную монету вручную)
- Карточки отсортированы по убыванию спреда — самое интересное сверху

## 6. Добавить ещё биржи

Уже подключены Bybit, OKX, Binance, Bitget, Gate.io, MEXC — этого более
чем достаточно для начала. Если понадобится ещё одна, в `exchanges.js`
нужна ещё одна функция вида `getAllХХХTickers()` по образцу остальных
(один bulk-запрос всех тикеров биржи → привести к виду `{ exchange, last,
bid, ask, volumeUsdt }` по каждой монете) и добавить её в массив
`EXCHANGES` внизу файла — сравнение подхватит её автоматически. Публичные
данные, ключ не нужен, только скажи, какую биржу добавить.

## 7. Включить автообновление вместо кнопки

Сейчас обновление — по нажатию кнопки, как и просил. Когда захочешь
автообновление раз в 10–30 секунд:

- в `.env` поставь `AUTO_REFRESH=true` и `AUTO_REFRESH_INTERVAL_SEC=20`
- скажи мне — добавлю `setInterval` в Mini App и/или периодическую рассылку
  алертов ботом, когда спред превышает порог

## Важно про API-ключи

Ключ Bybit, который ты уже получил, для этого трекера **не используется** —
цены (`tickers`) отдаются публично без авторизации. Держи ключ отдельно и
не добавляй его в код/чат, пока не понадобится реально торговать.
